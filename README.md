# ZapretHub

ZapretHub проверяет доступность выбранных сервисов, подбирает рабочую конфигурацию Flowseal Zapret и переключается на резервный VPN, если локальные варианты и свежий релиз исчерпаны.

## Запуск

Нужны Windows 10 или 11 и .NET 10 SDK. Соберите приложение в PowerShell из каталога проекта.

```powershell
dotnet build ZapretHub.slnx -c Release
Start-Process .\src\ZapretHub.App\bin\Release\net10.0-windows\ZapretHub.exe
```

При запуске Windows запросит права администратора для работы Zapret и управления службами WireGuard. ZapretHub сохраняет настройки и проверенные релизы в `%ProgramFiles%\ZapretHub\Data`. При первом запуске приложение скачивает ZIP из стабильного релиза Flowseal, сверяет SHA-256 и подбирает конфигурацию. Закрытие окна сворачивает приложение в трей. Пункт «Выход» завершает запущенный Zapret.

Если Zapret уже запущен отдельным процессом или службой, остановите его перед запуском через ZapretHub. В настройках можно изменить контрольный адрес, список проверяемых сервисов, интервал мониторинга и количество хранимых релизов.

## Подбор при сбое и Egorik

По умолчанию ZapretHub продолжает проверять связь, но ждёт подтверждения перед сменой активного конфига. Если запущена версия Egorik с поддержкой ZapretHub, включены распознавание речи и озвучивание, ассистент задаст вопрос. Ответьте «да» или «нет». Запрос задаётся один раз за сбой и отменяется, если связь восстановилась.

Если Egorik недоступен или ответ не получен, ZapretHub покажет уведомление. Нажмите «Найти стабильный» в окне или трее, когда можно ненадолго прервать соединение. Приложение повторно проверит текущий конфиг перед его остановкой.

Включите «Автоматически подбирать конфиг при сбое» в настройках, чтобы приложение переключалось само. В этом режиме голосовой запрос и уведомления о восстановлении отключены. Если выбран ручной VPN, подтверждение подключения по-прежнему выполняется в самом VPN-клиенте.

Оба приложения должны работать под одной учётной записью Windows. Они связываются через локальный именованный канал без внешнего сервера.

## Автозапуск

Для автозапуска установите приложение в защищённый системный каталог. Выполните из каталога проекта в PowerShell с правами администратора:

```powershell
$zapretHubApp = Join-Path $env:ProgramFiles 'ZapretHub\App'
dotnet publish .\src\ZapretHub.App\ZapretHub.App.csproj -c Release -o $zapretHubApp
Start-Process (Join-Path $zapretHubApp 'ZapretHub.exe')
```

В настройках включите «Запускать ZapretHub при входе в Windows». Приложение будет запускаться в трее через Планировщик заданий для текущего пользователя. Чтобы отключить автозапуск, снимите флажок и сохраните настройки.

## Резервный VPN

- **Ручное подключение.** Укажите EXE установленного клиента, например BlackTemple. При сбое ZapretHub откроет клиент. Нажмите «Подключить» в нём. Перед возвратом к Zapret отключите ручной VPN в его клиенте.
- **Автоматическое подключение.** Выберите уже установленную службу туннеля WireGuard. ZapretHub запустит службу и дождётся подтверждённого обмена с VPN-сервером. При возврате к Zapret приложение остановит туннель, если само его запустило. Для профиля с раздельной маршрутизацией включите в туннель трафик к контрольному URL, чтобы проверка могла инициировать обмен. [Документация WireGuard для Windows](https://git.zx2c4.com/wireguard-windows/about/docs/enterprise.md#tunnel-service)

## Тесты

```powershell
dotnet test --solution ZapretHub.slnx
```

Функциональные тесты используют локальный HTTP-сервер, временные архивы и тестовые процессы Windows. Для проверки сетевых настроек и переключения на реальный VPN используйте установленный клиент и рабочий профиль на целевой машине.
